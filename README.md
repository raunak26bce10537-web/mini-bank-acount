# Mini Bank Account Management System

## 📌 Project Overview

The **Mini Bank Account Management System** is a simple Python-based console application designed to perform basic banking operations.

The project allows users to create a bank account, deposit money, withdraw money, check their balance, and display account details.

This project demonstrates the use of **Python functions, dictionaries, loops, conditional statements, exception handling, and user input**.

---

## 🎯 Objectives

The main objectives of this project are:

- To create and manage bank accounts.
- To deposit money into an account.
- To withdraw money from an account.
- To check the current account balance.
- To display complete account details.
- To practice Python programming concepts.

---

## ✨ Features

The system provides the following options:

1. **Create Account**
   - Creates a new bank account.
   - Stores account number, account holder name, and initial balance.
   - Prevents duplicate account numbers.

2. **Deposit Money**
   - Allows users to deposit money.
   - Checks whether the account exists.
   - Prevents zero or negative deposits.

3. **Withdraw Money**
   - Allows users to withdraw money.
   - Checks whether sufficient balance is available.
   - Prevents withdrawal of zero or negative amounts.

4. **Check Balance**
   - Displays the current balance of an account.

5. **Display Account Details**
   - Displays:
     - Account number
     - Account holder name
     - Current balance

6. **Exit**
   - Safely exits the program.
